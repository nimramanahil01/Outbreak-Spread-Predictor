# COVID-19 Outbreak Spread Predictor

## 📌 Project Overview
This project analyzes global COVID-19 outbreak data using Python and predicts future confirmed cases using a Linear Regression Machine Learning model.

## 📂 Features
- Data Cleaning
- Data Analysis
- COVID-19 Trend Visualization
- Heatmap Visualization
- Top 10 Countries Analysis
- Machine Learning Prediction
- PyQt5 Dashboard

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- PyQt5
- Joblib

## 📁 Project Structure

## 🚀 How to Run

1. Install the required libraries:

```bash
pip install -r requirements.txt
```

2. Open the notebook:

```
notebooks/analysis.ipynb
```

3. Run all the notebook cells.
